# GeoRhizome AI
## Core Platform Repository

Welcome to the GeoRhizome AI core source repository. This directory houses the primary web application, server, and collector pipelines that drive the GeoRhizome AI ecosystem.

### Overview
This system is an enterprise-grade AI platform featuring:
- Seamless multi-agent collaboration
- Powerful local LLM inference and management
- Comprehensive knowledge ingestion pipelines with hardware-aware OCR

### Distribution
This codebase is strictly synchronized with the `GeoRhizome_AI-LTS` repository for automated multi-architecture Docker builds and Over-The-Air (OTA) employee distribution.
